1. Algoritmo Secuencial

            

              Las instrucciones se ejecutan línea por línea de arriba hacia abajo. Sigue siempre el orden: 1) Definir variables → 2) Leer datos → 3) Calcular con <- → 4) Escribir resultados.
            

          


          

            

              
Tipos de Datos

              
    
                
  • Entero: Cantidades exactas (ej. 5, 10, -2).
    • 
                
  • Real: Precios, notas o promedios con decimal (ej. 19.5).
    • 
                
  • Caracter / Cadena: Nombres o mensajes entre comillas ("Hola").
    • 
                
  • Logico: Verdadero o Falso.
    • 
              

            


            

              
Operadores y Funciones

              
    
                
  • + , - , * , / : Operaciones básicas
    • 
                
  • ^ : Potencia (ej. lado ^ 2)
    • 
                
  • MOD o % : Residuo de división entera
    • 
                
  • raiz(x), trunc(x), redon(x), abs(x)
    • 
              

            

          


          

            

              Ejemplo Secuencial: Venta en Tienda con 15% de Descuento
              
            

            
Algoritmo VentaTienda
    Definir precio, descuento, totalPagar Como Real;
    Escribir "Ingrese el precio del producto:";
    Leer precio;
    descuento <- precio * 0.15;
    totalPagar <- precio - descuento;
    Escribir "Descuento (15%): ", descuento;
    Escribir "Total a pagar: ", totalPagar;
FinAlgoritmo

          

        


        
        

          

            
2. Condicionales (Si - Entonces - SiNo)

            

              Permiten tomar decisiones. Si la condición después de Si es verdadera, se ejecuta lo que está debajo de Entonces; si es falsa, se ejecuta el bloque SiNo. También puedes encadenar condiciones con SiNo Si.
            

          


          

            

              
Comparadores

              
    
                
  • = : Igual que (ej. codigo = 1)
    • 
                
  • <> : Diferente de (ej. opcion <> 0)
    • 
                
  • < , > , <= , >= : Menor, mayor, menor o igual, mayor o igual
    • 
              

            

            

              
Conectores Lógicos

              
    
                
  • Y : Se deben cumplir las dos condiciones a la vez.
    • 
                
  • O : Basta con que se cumpla al menos una condición.
    • 
                
  • NO : Niega una condición.
    • 
              

            

          


          

            

              Ejemplo Condicional: Tarifa de Cine por Edad
              
            

            
Algoritmo TarifaCine
    Definir edad Como Entero;
    Escribir "Ingresa la edad del cliente:";
    Leer edad;
    Si edad < 12 Entonces
        Escribir "Boleta Infantil: $8,000";
    SiNo Si edad >= 60 Entonces
        Escribir "Boleta Adulto Mayor: $9,000";
    SiNo
        Escribir "Boleta General: $15,000";
    FinSi
FinAlgoritmo

          

        


        
        

          

            
3. Algoritmos Repetitivos (Ciclos)

            

              Repiten un grupo de instrucciones múltiples veces. Usa Contadores (cont <- cont + 1) y Acumuladores (total <- total + precio) inicializados en 0 antes del ciclo.
            

          


          

            

              
Ciclo PARA

              
Cuando conoces el número exacto de repeticiones.

              Para i <- 1 Hasta N Con Paso 1 Hacer
  ...
FinPara
            


            

              
Ciclo MIENTRAS

              
Evalúa la condición al inicio. Repite mientras sea verdadera.

              Mientras precio <> 0 Hacer
  ...
FinMientras
            


            

              
Ciclo REPETIR

              
Ejecuta al menos una vez y termina cuando la condición sea verdadera.

              Repetir
  ...
Hasta Que clave = 1234
            

          


          

            

              Ejemplo Repetitivo: Caja Registradora de N Productos
              
            

            
Algoritmo CajaRegistradoraEjemplo
    Definir n, i Como Entero;
    Definir precio, total Como Real;
    total <- 0;
    Escribir "¿Cuántos productos lleva el cliente?";
    Leer n;
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Escribir "Precio del producto #", i, ":";
        Leer precio;
        total <- total + precio;
    FinPara
    Escribir "Total a pagar: ", total;
FinAlgoritmo

          

        


        
        

          
🚫 Errores comunes que revisa el Analizador

          

            

              
1. Olvidar cerrar estructuras

              
Todo Si requiere su FinSi, todo Mientras su FinMientras, todo Para su FinPara y todo Repetir su Hasta Que.

            

            

              
2. No inicializar acumuladores o contadores

              
Antes de hacer total <- total + precio, debes escribir total <- 0; arriba del ciclo.

            

            

              
3. Bucle infinito en Mientras

              
Asegúrate de actualizar dentro del Mientras la variable que controla la condición (ej. volver a Leer o incrementar i <- i + 1).
